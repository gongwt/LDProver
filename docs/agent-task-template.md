# LDProver 单轮任务卡模板

复制到本轮共享任务记录，或粘贴进已有工单。派工人填写前三栏，执行与复审各更新自己的交付记录。短任务可合并栏位。

## 1. 决定什么

- 任务 ID / 状态 / 主责 / 协作者 / 集成人 / 复审人：
- 一句话问题与本轮交付：
- 目前事实及原始出处（文件、段落或数据行）：
- 待验证假设 / 竞争解释 / 足以否决假设的结果：

## 2. 从哪里开始

- 仓库、基线提交、影响本轮的未提交差异及文件标识：
- 实现者可写文件 / 测试者可写文件 / 共享接口归属：
- 依赖与交接顺序；本轮允许的编辑、运行、提交或发布操作：
- 启动必读材料（只列与决定直接相关的入口）：

## 3. 怎样验收与停止

| 项目 | 本轮预先填写 |
|---|---|
| 比较对象 | 基线、候选的唯一差异；开发题、已有胜证守卫、留出题 |
| 冻结配置 | 端、构建、起点与轨迹、规则、区域、开关、资源预算、允许的运行次数 |
| 主指标 | 直接回答本轮问题的量、分母、接受门槛和反例；数据不足如何判定 |
| 正确性 | 独立校验入口与通过条件；应拒绝的例子及预期原因 |
| 停止条件 | 到限、失败、无收益分别如何处置；是否保留实验开关 |

## 4. 执行交付与恢复点

- 候选版本 / 具体改动 / 复现命令与运行环境：
- 已执行哪组、花费多少、剩余授权；数据文件与证明文件位置及摘要：
- 已观察事实 / 尚未证实的解释 / 当前阻塞或下一步 / 接手人：

## 5. 独立复审

- 实际检查的候选与校验器版本，复核过的原始数据或反例：
- 裁决（接受、仅保留实验、退回或证据不足）及理由：
- 可对外声称的结果；尚未覆盖的范围；下一项待决定的问题：
